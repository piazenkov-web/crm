# Welcome to Moscow — выбранные компоненты

| Решение | Что получаем готовым | Что потребуется доработать |
| --- | --- | --- |
| [EspoCRM](https://github.com/espocrm/espocrm) | CRM: гости, обращения, сделки, задачи, интерфейс менеджеров | Карточки квартир и броней, предпочтения гостей, интеграции |
| [Chatwoot](https://github.com/chatwoot/chatwoot) | Чат сайта, переписка, рабочее место операторов | Подключение нашего ИИ, связь диалога с гостем и бронью |
| [LangGraph](https://github.com/langchain-ai/langgraph) | Библиотека управления сценариями ИИ | Сценарии продавца, бронирования, консьержа и поддержки |
| [pgvector](https://github.com/pgvector/pgvector) | Поиск по смыслу внутри PostgreSQL | Загрузка инструкций, фильтрация доступа и актуальности |
| [Celery](https://github.com/celery/celery) | Очереди фоновых задач | Напоминания, обработка вебхуков, повторные попытки и сверка статусов |
| [Keycloak](https://github.com/keycloak/keycloak) | Вход пользователей и управление ролями | Подключение кабинета, права сотрудников и проверка доступа к конкретной брони |
| [Apache Superset](https://github.com/apache/superset) | Панели аналитики и отчёты | Подготовка данных и расчёт загрузки, прибыли, повторных продаж |
| [LiveKit Agents](https://github.com/livekit/agents) | Основа голосового ИИ-помощника | Телефония, голосовые сценарии, подключение моделей речи |

Для первого запуска: EspoCRM + Chatwoot + LangGraph + PostgreSQL/pgvector + Celery. Keycloak, Superset и голос добавляются по мере готовности функций.

## Альтернативы

| Решение | Когда выбирать |
| --- | --- |
| [Dify](https://github.com/langgenius/dify) | Быстрый прототип ИИ с визуальным редактором и базой знаний; альтернатива первоначальной разработке на LangGraph |
| [n8n](https://github.com/n8n-io/n8n) | Вспомогательные уведомления, обмен данными и регулярные отчёты |
| [QloApps](https://github.com/Qloapps/QloApps) | Кандидат на собственную PMS вместо RealtyCalendar; пригодность проверяется на пилоте |

Dify и n8n имеют специальные условия лицензирования. Дополнительно сохранён ERPNext, ранее предложенный для корпоративного учёта. Альтернативы не требуется запускать одновременно.

Собственный backend реализует адаптер RealtyCalendar, операции с котировками и бронями, связь платежей, правила доступа к инструкциям и кабинет. Возможности сторонних API подтверждаются отдельно. Для 10 млн клиентов центральные данные и историю проектируем отдельно от интерфейсов CRM; совместная производительность проверяется испытаниями.

Исходники: welcome/programs/. Коммиты: welcome/components-lock.json. План: welcome/docs/IMPLEMENTATION_GUIDE_RU.md. Наличие исходников на сервере не означает, что все приложения установлены или соединены.
