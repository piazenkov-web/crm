## Получение полного набора исходников

Рекомендуется Linux: один из сторонних проектов содержит имена, несовместимые с обычной рабочей копией Windows.

```sh
git clone --branch welcomemoscow --single-branch --recurse-submodules https://github.com/piazenkov-web/crm.git
```

Для уже скачанной ветки:

```sh
git submodule update --init --recursive
```

Подмодули сохраняют исходники и лицензии оригинальных проектов. Они не являются установленными приложениями. Версии перед промышленным запуском нужно проверить и согласовать. Полный QloApps доступен через подмодуль на Linux; Windows-ограничения описаны в welcome/README.md.

Зависимости node_modules, локальные секреты, кэши, сборочные архивы и локальное состояние инструментов не публикуются. Существующая CRM не заменена новыми компонентами. Сохранение в GitHub не является развёртыванием на сервере.
