## Что запущено

Отдельный Docker Compose проект welcome-platform-infra:

- PostgreSQL 16 с pgvector 0.8.7: контейнер welcome-platform-infra-postgres-1, статус healthy.
- Redis 7: контейнер welcome-platform-infra-redis-1, статус healthy.

Образы закреплены по digest в deploy/infrastructure/compose.yaml. Контейнеры используют отдельные volumes и внутреннюю сеть; порты БД и Redis на сервер не опубликованы. Пароли созданы на сервере в исключённом из Git локальном .env, права 600.
