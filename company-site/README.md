# Welcome Moscow — личные кабинеты

Исходный публичный каталог сохранён в public/. Серверный кабинет: /cabinet.
Вход через ChatGPT; записи D1 отбираются по подтверждённой серверной идентичности и типу кабинета. Роль в интерфейсе не предоставляет доступ к чужим данным.

Компания: реквизиты, сотрудники, черновики поездок, повторный подбор, печатный черновик заявки.
Гость: профиль, сохранение черновика обращения; инструкции и документы ожидают подтверждённой привязки бронирования.
Собственник: профиль; объекты, занятость и отчёты ожидают проверенного назначения прав.
Во всех кабинетах: калькулятор 5% от оплаченной суммы. Он не создаёт финансовое начисление. База расчёта — оплаченная сумма бронирования. Распределение между получателями пока не утверждено.

Не подключены: подтверждение брони/платежа серверными событиями RealtyCalendar, автоматическое начисление и перечисление вознаграждения, доступ коллег, загрузка утверждённых договоров и счетов. Клиент не может менять оплату, права или начисления через API.

Развёртывание: Cloudflare Workers + D1 через Sites, текущий публичный адрес и project_id сохранены.
