# Первый инфраструктурный этап

Отдельные PostgreSQL 16 с pgvector и Redis 7 для будущего backend и очереди. Образы закреплены по digest, проверенному при получении на сервере. Сеть internal, опубликованных портов нет. Данные находятся в отдельных Docker volumes проекта welcome-platform-infra.

```sh
sh deploy/infrastructure/bootstrap.sh
sh deploy/infrastructure/verify.sh
```

Пароли генерируются на сервере и остаются в локальном .env с правами 600. Они не добавляются в Git. Не запускать docker compose down -v: это удалит данные.

verify.sh создаёт временные контрольные записи, перезапускает только эти два новых контейнера, проверяет сохранность и удаляет контрольные записи. Выполнять на первоначальном стенде, до подключения приложений. Тест не должен выполняться одновременно несколькими процессами.

Бизнес-миграции и приложения пока не подключены. Контрактный каркас developer-kit не является готовым backend. Для остальных приложений требуются собственные БД/права, согласованные версии, настройка и поэтапная приёмка.
