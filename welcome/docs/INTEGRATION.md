# План интеграции

```text
RealtyCalendar → вебхуки → Наш сервис → REST API EspoCRM
                              ↕
                     LangGraph + модель ИИ
                              ↕
                         API Chatwoot
                              ↕
                       Гость / оператор
```

1. Создать в EspoCRM сущности «Квартира», «Собственник», «Бронь» и карточки гостей. У брони хранить квартиру, гостя, даты, статус и внешний идентификатор RealtyCalendar.
2. Разработать сервис получения и проверки вебхуков RealtyCalendar. Создавать или обновлять бронь через API EspoCRM по внешнему идентификатору, обрабатывать повторные события. Первоначальную загрузку броней решить отдельно.
3. Настроить чат сайта и один канал в Chatwoot. Передавать входящие сообщения нашему сервису через вебхук.
4. Разработать консьержа на LangGraph: определять гостя и бронь, получать разрешённые данные, отправлять ответ через Chatwoot. При передаче оператору прекращать ответы бота.
5. Проверить создание, изменение и отмену брони, повторный вебхук, недоступность CRM, соответствие ответа квартире и передачу оператору.
6. Добавить Superset после подготовки данных и отчётов.

Пилот: 10–30 квартир, чат сайта и один мессенджер. Готовность к 10 000 квартир требует отдельной проверки нагрузки.

RealtyCalendar остаётся источником броней. Получение вебхуков не подтверждает доступность обратного создания или изменения броней.

Документация:

- EspoCRM REST API: https://docs.espocrm.com/development/api/
- RealtyCalendar вебхуки: https://confluence.lan.realtycalendar.ru/kb/opisanie-webhook-30958558.html
