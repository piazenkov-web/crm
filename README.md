# ТЕРРА CRM

Первая рабочая версия CRM: клиенты и этапы сделок, задачи со сроками и приоритетами, документы клиентов, поиск, фильтры, архив и восстановление. Интерфейс на русском языке, адаптирован для телефона.

## Запуск

Скопируйте `.env.example` в `.env`, задайте уникальный `CRM_PASSWORD`, затем выполните `docker compose up -d --build`. Не используйте SSH-пароль для входа в CRM. HTTP доступен на порту 8080; HTTPS-адрес бесплатного туннеля можно получить командой `docker logs terra-crm-tunnel`. Для локального запуска используйте `CRM_PASSWORD=... DATA_DIR=data uvicorn app:app --port 8091`.

Python 3.12, FastAPI, SQLite (WAL). База и файлы хранятся в томе `crm-data`; не запускайте `docker compose down -v`, чтобы не удалить данные. Никаких внешних ключей и платных сервисов не требуется.

## Ограничения первой версии

Один общий администратор, без отдельных ролей сотрудников. Сессия действует 12 часов и заканчивается при перезапуске приложения. Документы до 10 МБ; они скачиваются после авторизации. Архивирование обратимо. Генерация банковских документов, OCR, телефония, Chatwoot и ИИ не реализованы.

Сайт доступен по HTTPS через Cloudflare Tunnel. Общий пароль администратора и временный адрес туннеля остаются ограничениями первой версии. Для настоящих данных нужны постоянный домен, отдельные роли пользователей и регулярные резервные копии. HTTP-порт 8080 сохраняется для совместимости; для входа используйте HTTPS-ссылку.

## Резервная копия

Для согласованной копии остановите контейнер, сохраните весь `/data` (база и `files/`), затем запустите контейнер. Храните копии вне сервера. Том сохраняется при обычном пересоздании контейнера.

## Открытие в Telegram

HTTPS-ссылку из `docker logs terra-crm-tunnel` можно отправить в «Избранное» или любой чат и открыть в браузере Telegram. Бот и Telegram Mini App не требуются. Используется обычная авторизация CRM по паролю. Автоматического входа по аккаунту Telegram нет.

Текущая проверенная ссылка: [открыть ТЕРРА CRM](https://biotechnology-bomb-vaccine-buy.trycloudflare.com/).

Полный отчёт о тестировании: [reports/TEST_REPORT.md](reports/TEST_REPORT.md).

На учебном сервере rootless Docker запрещает порты 80 и 443. Применён [Cloudflare Quick Tunnel](https://developers.cloudflare.com/cloudflare-one/networks/connectors/cloudflare-tunnel/do-more-with-tunnels/trycloudflare/) с исходящим зашифрованным соединением. Он предназначен для разработки: случайный адрес меняется при перезапуске туннеля. Для постоянного адреса потребуется домен и именованный Cloudflare Tunnel. Данные CRM остаются в томе на вашем сервере; внешний сервис передаёт веб-трафик.

Uvicorn доверяет прокси-заголовкам только IP контейнера туннеля, а не всем посетителям HTTP-порта. Сессионные cookie по HTTPS имеют флаг Secure.
