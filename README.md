# ТЕРРА CRM

Первая рабочая версия CRM: клиенты и этапы сделок, задачи со сроками и приоритетами, документы клиентов, поиск, фильтры, архив и восстановление. Интерфейс на русском языке, адаптирован для телефона.

## Запуск

Создайте `.env` с `CRM_PASSWORD=<длинный уникальный пароль>`, затем выполните `docker compose up -d --build`. Откройте порт 8080. Не используйте SSH-пароль для входа в CRM.

Python 3.12, FastAPI, SQLite (WAL). База и файлы хранятся в томе `crm-data`; не запускайте `docker compose down -v`, чтобы не удалить данные. Никаких внешних ключей и платных сервисов не требуется.

## Проверки

`pip install -r requirements.txt httpx==0.28.1`

`python -m unittest discover -s tests -v`

`node --check static/app.js`

## Ограничения первой версии

Один общий администратор, без отдельных ролей сотрудников. Сессия действует 12 часов и заканчивается при перезапуске приложения. Документы до 10 МБ; они скачиваются после авторизации. Архивирование обратимо. Генерация банковских документов, OCR, телефония, Chatwoot и ИИ не реализованы.

Текущий сервер использует HTTP: до настройки HTTPS используйте только вымышленные данные. Для настоящих данных нужны домен, HTTPS, роли пользователей и регулярные резервные копии.

## Резервная копия

Для согласованной копии остановите контейнер, сохраните весь `/data` (база и `files/`), затем запустите контейнер. Храните копии вне сервера. Том сохраняется при обычном пересоздании контейнера.
